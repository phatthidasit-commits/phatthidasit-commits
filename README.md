## 📚 Development Journey

การเรียนรู้ของหนูเน้นการลงมือทำจริง (Hands-on) โดยเริ่มปูพื้นฐานผ่าน Coursera และนำมาสร้างโปรเจกต์เพื่อแก้ปัญหาที่สนใจ

ในการพัฒนาโครงงาน หนูประยุกต์ใช้เครื่องมือ AI เป็นผู้ช่วยในการเขียนและปรับปรุงโค้ด (Pair-programming) โดยที่หนูเป็นผู้วาง Architecture, ออกแบบ Logic, กำหนดฟังก์ชัน, ตั้งค่า Deployment และ Debug ระบบด้วยตัวเอง ซึ่งกระบวนการนี้ช่วยให้หนูเข้าใจการทำงานของซอฟต์แวร์ได้ลึกซึ้งและรวดเร็วขึ้น

หนูยังคงเรียนรู้และฝึกฝนอย่างต่อเนื่อง เพื่อพัฒนาตัวเองให้เป็นนักพัฒนาที่สามารถสร้างสรรค์เทคโนโลยีที่ตอบโจทย์ผู้ใช้งานได้ดียิ่งขึ้นในอนาคต
